# P2-10 audit: explicit XML values and validated element fragments

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: XsdXmlValue and native XML fragment generation; explicit UTF-8/length input to XmlReader; exception-preserving schema callbacks; focused and independent tests; public/design/release documentation, documentation build configuration, and current corpus report digests.

XsdXmlValue keeps source XML authoritative, exposes immutable copy-on-write views, root expanded names, scoped QName resolution and independent readers, and rebuilds transient state after Serializable reconstruction. XML generation accepts ^xml^ keys, validates a complete single-element document, rejects DOCTYPEs/NULs, preserves ordered content and namespace scope, and checks cancellation. It does not bypass XSD validation or yet add object consumption to SOAP/providers; that remaining P2 deliverable is explicitly tracked.

The four focused native/API suites pass 48 cases (xml-literal 8/44, wsdl-xml-value 10/59, XML 25/189, SAX stream 5/15). The full 25-suite run passes 387 Qore cases. Documentation-only WebContentUtil changes pass another 85 cases / 346 assertions. Independent XML-value tests check six original/reconstructed documents with exact lexical/QName/mixed-content assertions and libxml2 plus pinned Xerces verdicts. Full Python retains only the six already-routed P4/P6 subtest failures in two of 72 tests; there are no new failures. Strict corpus: 38 descriptions / 140 directions, zero selected failures. All 384 broad failures remain visible, with no missing or skipped cases. Recursive report comparison changes only the WSDL source digest.

Documentation inputs now contain public QPP declarations rather than implementation C++; generated option documentation is a public page, WebService's doc comment is attached to its class, links/parameter markup are corrected, and the final documentation pass uses generated user-module and supplied core tags with warnings enabled. XML/WSDL/WebContentUtil docs pass without warnings. Native Debug build uses /usr, matching /usr/bin/qore. No installation, push or unrelated repository edit.

The full astparser grammar and JNI location prerequisites are tracked separately. Memory verification remains open: PCRE2 JIT uninitialized-condition reports also reproduce in a standalone C executable without Qore/XML; no workaround or suppression has been applied. This report does not authorize committing before that gate is resolved.
