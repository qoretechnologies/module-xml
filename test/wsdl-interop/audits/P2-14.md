# P2-14 audit: inherited attribute and simple-content constraints

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only changes after P2-13 in WSDL, new attribute derivation Qore/Python
regressions, release notes, schema identity design, README and current reports.
Required/fixed constraints and simple-type ancestry are validated before inherited
uses are replaced. Extensions reject duplicate expanded uses. Inline simple-content
restrictions must derive from the effective simple type of their complex base.

WSDL SHA-256: `f8e6bbc1158b4cbd57a00e07da79a5b5f060a3948cb4c474d6970a3e906d7c78`. Incremental diff:
`/tmp/wsdl-p2-14-WSDL.diff`; baseline:
`/tmp/wsdl-p2-13-pre-constraints-WSDL.qm`.

Before the fix six of seven new Qore cases failed because WSDL-ERROR was absent
(`/tmp/wsdl-p2-14-before.log`). Final focused run passes seven cases / 69 assertions
(`/tmp/wsdl-p2-14-focused.log`); all 25 existing affected suites pass
(`/tmp/wsdl-p2-14-affected.log`), for 379 combined Qore cases. The independent
matrix has 44 schema variants, 88 parses through actual SOAP 1.1/1.2 descriptions,
and 40 request/response documents with exact names, text and attributes
(`/tmp/wsdl-p2-14-independent.log`). Both independent tests pass.

Full Python discovery runs 79 tests with 14 known subtest failures: eight P3
integer lexical rejection, four P4 nested-choice exclusivity and two P6 selected
binding envelope mismatch. No new failures or skips
(`/tmp/wsdl-p2-14-python.log`). WSDL docs are warning-free
(`/tmp/wsdl-p2-14-docs.log`). Survey and full coverage compare recursively equal
to P2-13 except verified module digest, with zero strict failures and 360 broad
failures; missing/skipped stages remain zero. Current reports are copied from
`/tmp/wsdl-survey-p2-14.json` and `/tmp/wsdl-coverage-p2-14.json`.

[XSD 1.0 complex type property mapping](https://www.w3.org/TR/xmlschema-1/#Complex_Type_Definition_details),
[derivation-ok-restriction](https://www.w3.org/TR/xmlschema-1/#derivation-ok-restriction),

[ct-props-correct](https://www.w3.org/TR/xmlschema-1/#ct-props-correct).
The second-edition errata were checked. libxml2 accepts restrictions that drop,
replace with default, or change a base fixed constraint. The exact six cases
(simple/complex variants) remain explicit oracle disagreements in the matrix;
Xerces and Qore reject as required by derivation-ok-restriction.2.1.3. Omitted
uses stay inherited by the property mapping; that behavior is not weakened.
Scalar lexical/value equivalence remains owned by P3 and final/block constraints
by P5. Remaining attribute wildcard composition is recorded in P2/P5 work.
