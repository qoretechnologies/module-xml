# P2-21 audit: retained XML consumers

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Status: **commit gate not clear**. All 62 checklist items were reviewed; error
handling/correctness retain explicit failures requiring follow-up. P2 is still
in progress. No commit or push was made.

Scope: WSDL carrier/schema/provider/example and SOAP sender/receiver APIs after
P2-20, SoapClient's new option, SoapHandler's new registration option, focused and
independent tests, design/release notes and current reports. Older uncommitted
P2-10 through P2-20 edits retain their separate audits. The five design guides

Root causes and fixes: flat native conversion discarded source lexical/order
information; subtree output omitted inherited namespaces; provider component-graph
serialization referenced unresolvable internal types; optional XML providers did
not honor base optionality; one-way native decoding required a nonexistent output
description; catch-all validation wrapped interruption errors. The implementation
retains final XML carriers, uses source-backed reconstruction, preserves native
defaults, applies both existing decode/encode checks, keeps output-prefix allocation
private and propagates cancellation. Positive SOAP fixtures use comments/CDATA;
processing instructions remain pure-XML coverage and negative SOAP checks.

Open findings:

1. libxml2 2.12.10 reports `urn:quoted&#38;more` for an ampersand-containing URI.
   Rebuilding attributes therefore escapes it again. A standalone C reproducer
   (`/tmp/wsdl-p2-21-libxml-namespace.c`) confirms the behavior with zero valgrind
   errors/leaks. Its comparison with XML_PARSE_NOENT is diagnostic only; production
   flags are unchanged. Upstream
   [v2.12.10 parser.c](https://github.com/GNOME/libxml2/blob/v2.12.10/parser.c) and
   [v2.13.9 parser.c](https://github.com/GNOME/libxml2/blob/v2.13.9/parser.c) show the
   namespace-specific expansion fix. User approval for a compatibility adaptation
   or a fixed dependency requirement is pending under the no-workarounds rule.
2. Native WSMessageHelper ignores required wildcard slots when generating examples.
   The independent test keeps all 16 invalid examples as failures; P5 owns complete
   wildcard/example generation. This is not a conformance pass.
3. Inherited xml:lang/xml:space/xml:base context still needs representation/consumer
   integration; current child extraction copies namespace declarations only.
   This remains P2/P5 work. P3/P4 scalar/particle and P5 dynamic semantics, P6/P8
   nonliteral/type/attachment integration remain explicit later-phase requirements.
4. P2-10's required native valgrind gate still needs the earlier PCRE2 JIT decision.
   This increment adds no C++ or astparser/JNI edits or builds and does not clear it.
