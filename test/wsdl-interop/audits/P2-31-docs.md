# P2-31 final audit: public documentation and phase acceptance

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: XML CMake public documentation inputs/tag dependencies/compiler standard,
README and native generation-option/release documentation, six known-owned
WebContentUtil comment fixes, and execution/README/PLAN/audit records. Historical
P2-10 through P2-23 audits retain intermediate results and explicitly refer to
the superseding acceptance records. Runtime Qore and C++ logic is unchanged.

The full audit-changes skill and referenced core module structure, sandboxing,
cooperative cancellation and DataProvider guides were reviewed. The documentation
fixes eliminate accidental implementation-file scanning, missing final-pass tag
dependencies, duplicate anchors, invalid references and unescaped literal markup.
The actual local Qore header build exposed its C++17 requirement; CMake now selects
that standard for Qore 3.0 while retaining C++11 for older releases and honoring
a higher caller-selected standard. Core f23e5307a fixes the two-pass helper on
CMake before 3.21, tested on 3.18.4 and 4.3.0 with the parent failure reproduced.

Validation uses /tmp/wsdl-docs-review/build-debug (Debug, /usr, local core package),
local fixed JNI and existing astparser artifacts, without installation or rebuild
of astparser. All final documentation warnings remain enabled. P2 acceptance and
known independent P3/P4/P5/P6 diagnostics are listed in EXECUTION.md; none are
converted to passing tests. No push.
