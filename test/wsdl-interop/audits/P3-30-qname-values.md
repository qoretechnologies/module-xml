# P3-30 audit: explicit QName values and native namespace identity

Copyright (C) 2026 Qore Technologies, s.r.o.

Applied all 62 audit-changes items and the referenced module structure,
sandboxing, cooperative cancellation and DataProvider checklist/development
guides to the final changes. Scope includes explicit QName values/providers,
the private dependency corrections and configure probe, source distribution,
regressions, current reports, documentation and evidence. Main Qore is unchanged.

The audit added missing source-distribution entries and NOTATION coverage for
the shared native QName comparison. A final value review also kept explicit
QName objects intact: converting a no-namespace object to lexical text would
let later provider conversions assign a default namespace. Repeated conversion
and successive-provider tests now verify preserved identity. Source hashes, negative override tests and
already-corrected override builds verify the dependency edits. The initial
worker Valgrind run used PCRE2 JIT and reproduced its already recorded external
diagnostic; final runs use the previously authorized interpreter control.
The existing core DWARF-reader warning remains a P9 environment finding.

Checklist: **22 Pass, 40 N/A, 0 Fail**. Final tests and artifact evidence are in
[EXECUTION.md](../EXECUTION.md). No push or installation is part of this change.
