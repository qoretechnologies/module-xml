## Scope and evidence

Array item QNames now use the declaration scope of the wsdl:arrayType annotation.
Finalization uses the resolved item/canonical identity and resets its completion
flag on failure. User-defined array types use their schema target namespace.
A collision test exposed child schema prefixes being renamed after types captured
them. Child contexts now reserve parent output maps before allocating prefixes,
using copy-on-write snapshots and target URI reuse; input scopes stay local.

Five of six initial cases failed before the fix. Final focused suite: nine cases /
46 assertions, including wrong/unbound/default/no namespace, colliding local type
names, canonical-only registries, failed additions, exact typed values, provider
metadata, reconstruction and output prefixes across added and nested contexts.

All 339 Qore cases in 21 suites pass. Full Python: 71 tests, 69 passing tests,
with the same six P4/P6 subtest failures in two tests and no errors or warnings.
Final namespace/composition/array/SOAP suites and four independent attribute tests
were rerun after the copy-on-write refinement. Both corpus reports were regenerated
and every row compared: only the module digest changes. Strict 38 descriptions /
140 directions pass, with 384 broad diagnostic failures and no missing/skipped
cases. This is incremental acceptance, not P2 phase acceptance or P8 wire compliance.

A concurrent core build redirected the source DataProvider symlink to a stale Debug
artifact. The resulting required-field failure was traced to that dependency and
resolved by explicitly selecting the verified Release artifact directory before
core qlib. No core file, symlink or installation was changed here. The README
records the invocation; EXECUTION.md records the artifact digest and cause.
