## Findings fixed during review

- Empty namespace keys previously collided with legacy local aliases: canonical
  `{}name` keys now preserve distinct identity, without changing public bare aliases.
- Schema serialization needed exported source metadata, saved dependency bytes and
  the current base path; missing legacy source data now raises a descriptive error.
- Fixed namespace resolution exposed acceptance of grammar-invalid historical
  sources. Ordered construction validation now rejects imports after declarations
  and unexpected schema children, with original XML and oracle evidence preserved.
- WebService reconstruction discarded inherited options after the XsdSchema extraction,
  losing relative import bases. It now uses the restored options, with a failing-before
  callback/import-base regression and compatibility with older local option storage.
- QName splitting alone accepted malformed names and lost trailing empty components.
  Complete colon shape, XML whitespace and Unicode NCName checks are now tested.
