# P2-17 audit: element declaration consistency

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only changes after P2-16, new focused/independent tests, documentation
and refreshed corpus reports. Baseline `/tmp/wsdl-p2-16-pre-element-consistency-WSDL.qm`;
reviewed diff `/tmp/wsdl-p2-17-WSDL.diff`. Final WSDL SHA-256: `ed4e9532cfa12e67c8a1798a48a2c49bdec8e7288217e6aad0c18fe458bffe26`.

Root cause: direct/group/base field maps overwrote earlier declarations with the
same expanded name, preventing type-consistency validation. Named groups also
ignored nested compositor declarations. Construction now retains declarations
before merging, checks resolved type identity, and combines checked group/base
signatures. Nested group declarations reach existing field/provider consumers.
Repeated references to one declaration preserve its component identity, including
an anonymous type; distinct local anonymous declarations do not become identical
merely because their source text matches. Ordinary optional particles contribute
their declarations; minOccurs=maxOccurs=0 particles do not. Extensions combine
base content; restrictions check their replacement content.

Normative references: [XSD 1.0 model-group constraints and EDC](https://www.w3.org/TR/xmlschema-1/#cos-element-consistent),
[element component mapping](https://www.w3.org/TR/xmlschema-1/#element-element),
[model-group component mapping](https://www.w3.org/TR/xmlschema-1/#element-sequence),
[component identity](https://www.w3.org/TR/xmlschema-1/#key-eq).
The second-edition errata contain no change to these rules. Reuse of one
anonymous declaration is interpreted by component identity, supported by both
independent implementations; the check does not confuse repeated references with
distinct declarations. Implicit substitution-group declarations retain P5
ownership; this increment does not implement P4 ordered particle matching.

The isolated P2-16 baseline fails five of seven focused cases
(`/tmp/wsdl-p2-17-before.log`). Final focused suite passes seven cases / 49
assertions, including direct/nested conflicts, named/anonymous/reference identity,
namespace/scope separation, inheritance, zero-occurrence spellings, rollback and
shared 32-level group graphs. All 29 affected suites pass: 397 Qore cases
(`/tmp/wsdl-p2-17-affected.log`). No requiredness changes survive failed additions.

Independent tests pass 30 schema graphs through 60 actual SOAP 1.1/1.2 binding
parses and 20 request/response documents. They check precise WSDL/SOAP error
categories, expanded names, order, integer zero/boolean false, provider types,
generated examples and reconstructed services (`/tmp/wsdl-p2-17-independent.log`).
Recorded oracle discrepancies are explicit assertions, without skips:

- libxml2 accepts 13 conflicting models and rejects two valid +00 occurrence
  spellings. Qore enforces the normative type/occurrence rules.
- Xerces omits EDC checks on the two unused conflicting named groups; XSD 1.0
  section 3.8.6 applies constraints to all model groups. Qore rejects both.

Full Python: 85 tests with only 14 tracked subtest failures (eight P3 lexical,
four P4 choices, two P6 binding-version), no new failure/skip
(`/tmp/wsdl-p2-17-python.log`). WSDL docs build without warnings/errors
(`/tmp/wsdl-p2-17-docs.log`). Survey and full coverage are recursively identical
to P2-16 except the WSDL source digest: zero strict failures, 360 broad failures,
no missing/skipped stages. The installed Qore and local XML artifact are unchanged.

All 62 audit-changes checklist items follow. The skill and its five referenced
core design guides were read during this execution. No native/astparser edits,
commit, installation or push; P2-10's native memory decision remains open.
