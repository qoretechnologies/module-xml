# P2-23 dependency selection and regex memory-check control

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Scope: the libxml2 build-provider increment and its tests/docs in module-xml,
and the PCRE2 process switch in Qore. Earlier P2-10 through P2-22 audits retain
ownership of their uncommitted implementation. Unrelated WebContentUtil and
JinaDataProvider work is excluded. Astparser sources and tests are untouched.
Qore prerequisite commit: `6efa18fc5` on develop (2026-09-08), six scoped files
including its independent full audit; no push. XML changes remain uncommitted.

The user's 2026-09-08 instruction selects programmatic PCRE2 JIT control and a
CMake behavioral probe with FetchContent fallback for affected libxml2. This
supersedes the earlier requests to approve a separate PCRE2 build or a module
namespace-decoding workaround. Neither of those earlier approaches was applied.

Root causes and implementation:

- PCRE2 already accepts `PCRE2_NO_JIT` at match time. Qore now reads exactly
  `QORE_PCRE2_NO_JIT=1` once at first regex use, skips `pcre2_jit_compile`, and
  forces interpreter matching without allocating its optional per-thread JIT
  context/stack. The flag is immutable after initialization and does not affect
  LLVM JIT. Other values retain normal behavior. This changes testing execution
  paths explicitly; it does not assert that JIT has been memory-checked.
- libxml2 2.12.10 misdecodes ampersands in namespace URIs. A CMake `try_run`
  checks actual reader namespace identity for named/decimal/hex references and
  literal entity-looking text. Passing distribution backports are accepted.
  AUTO falls back on an absent/failing/unverifiable system library; SYSTEM
  rejects it; BUNDLED explicitly chooses FetchContent. Cross builds use an
  emulator or select the fixed fallback. Results are reprobed on reconfigure.
- The fallback is the latest stable release verified from GNOME on 2026-09-08,
  libxml2 2.15.4, URL/SHA-256 pinned. Private static linkage and hidden symbols
  prevent interference with older libraries in the host process. Upstream
  install rules are excluded; only the module and retained dependency notices
  are installed. Offline source overrides must have the pinned version.
  Parent BUILD_SHARED_LIBS remains untouched. CMake 3.18 is required by upstream.
  Autotools retains its explicit system-dependency workflow.

Additional HTTP/TLS diagnosis after the core commit: the minimal plain HTTP
reproduction with the new core switch reports 352 bytes possibly lost with the
default glibc stack cache, and 704 bytes in two blocks when the stack cache is
disabled for diagnosis. Neither run has definite/indirect loss. Disabling the
cache therefore does not resolve the finding and is not adopted as a test
workaround. `qore_cleanup()` waits on `tp_thread_counter`, but `q_run_thread()`
decrements that counter immediately before returning to pthread, before native
TLS destruction has necessarily finished; `ThreadEntry::cleanup()` detaches the
thread instead of joining it. This is the next lifetime investigation, not a
confirmed repair. Logs: `/tmp/wsdl-p2-23-http-{default,no-cache}.log`.
The valgrind Debug-info warning also reproduces with `qore --version`, before
executing any XML or test script (`/tmp/wsdl-p2-23-vg-qore-version.log`).

Logs: `/tmp/wsdl-p2-23-{regex-tests,provider-tests-verified,affected,python,
survey-final,coverage,docs}.log`, `/tmp/wsdl-p2-23-vg-*.log`.
