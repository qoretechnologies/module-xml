# P2-11 audit: document element namespace identity

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

This incremental audit covers the changes after the uncommitted P2-10 snapshot:
XML element namespace expansion/restoration, document body/header matching,
SoapHandler routing preservation, regressions, API/release/design documentation
and refreshed corpus reports. P2-10 native fragments/XML values remain a separate
audited prerequisite with an open PCRE2 memory-check decision. No commit is made
or authorized while that prerequisite gate is open. Astparser is owned by the
user's parallel audit and has not been edited, staged or rebuilt here.

`/tmp/wsdl-p2-11-WSDL.diff`; the pre-collision snapshot is
`/tmp/wsdl-p2-11-pre-collisions-WSDL.qm`.

Verification: `/tmp/wsdl-p2-11-final-affected.log` and per-suite logs (361 cases
in 23 suites), `/tmp/wsdl-p2-11-python.log` (74 tests, only six routed P4/P6
subtest failures), `/tmp/wsdl-p2-11-docs-SoapHandler-final.log` and WSDL docs
in `/tmp/wsdl-p2-11-docs-final.log`. The final SoapHandler-specific rebuild has
zero warnings; its earlier stale external reference was replaced by a direct
parameter description. No warning suppression was introduced.

Final reports are `/tmp/wsdl-survey-p2-11-final.json` and
`/tmp/wsdl-coverage-p2-11-final.json`, copied to the repository after recursive
comparison. The request survey has 972 valid/32 rejected outputs (previously
960/44), and eight valid-input/invalid-output cases (previously 20). Coverage
has 360 broad failures (previously 384), zero strict selected failures and no
missing/skipped stages. Both independent output validators report 1,944 valid
and 64 rejected outputs. Value checks remain 128 pass, 40 fail, 264 unreachable,
1,840 unassessed; those gaps remain visible. This is not P2 or plan acceptance.

and [XSD element validity](https://www.w3.org/TR/xmlschema-1/#cvc-elt).
