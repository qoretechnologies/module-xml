# P3-36 audit: reader schema attachment and resources

Copyright (C) 2026 Qore Technologies, s.r.o.

The full audit-changes skill and applicable module-structure, sandboxing and
cooperative-cancellation guides were applied to the exact C++/QPP implementation,
Qore/Python regressions, implemented design, examples, release notes and evidence.
DataProvider checklist items were individually assessed as not applicable.

Checklist: **26 Pass / 36 N/A / 0 Fail**. The review corrected legacy
input-buffer ownership on allocation failure, rechecked reader state after reentrant
callbacks, retained explicit-NOTHING callback validation, enabled HTTPS verification,
and covered oversized/empty streams and partial-read failure/cancellation. Both
Debug and Release builds preserve evaluation of the resource-open call used by the
assertion, with its result marked maybe_unused for Release.

Exact artifacts, test counts and open independent findings are recorded in
[xml-reader-schemas-evidence.md](../xml-reader-schemas-evidence.md) and
[EXECUTION.md](../EXECUTION.md). Core prerequisites were separately committed and
audited. No production WSDL source, upstream fixture or dependency probe changes
are included. P3 and P9 acceptance remain open.
