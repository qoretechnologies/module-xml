# P3-25 audit: duration lexical values

Copyright (C) 2026 Qore Technologies, s.r.o.

Final audit of the tested duration lexical/native increment; all current-change verification gates are complete.

Scope: exact duration lexical/native conversion, validated scalar provider and known-base identity; Qore/Python/local-HTTP tests; independent component reference and validator fixture; implemented design, examples, release notes and current reports. Calendar work is committed separately as `9f6e735`; no core changes are included.

The full audit-changes skill and applicable module-structure, sandboxing, cancellation and DataProvider guides apply. This schema scalar provider does not register application actions or timestamp record fields. The audit found a missing known-provider identity branch: duration providers could be supplied as numeric/calendar bases. A negative regression reproduced it; the shared identity check now rejects the mismatch.
