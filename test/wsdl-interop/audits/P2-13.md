# P2-13 audit: WSDL message part namespace identities

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: incremental changes after P2-12, comprising message/part QName scope,
argument alias selection, element wire-name generation, multipart examples,
regressions, docs and refreshed reports. Part names remain provider/binding
keys, while colliding element aliases use expanded names. The existing
identical-expanded-element restriction is explicitly tracked as P6 work; it
is not represented as a WSDL requirement.

WSDL SHA-256: `11c598aec866cbcf6d31babc80f84961f668cd7cb8a80635e7f37b718e235252`. Incremental diff:
`/tmp/wsdl-p2-13-WSDL.diff`; pre-increment snapshot:
`/tmp/wsdl-p2-12-pre-message-identity-WSDL.qm`.

Verification: `/tmp/wsdl-p2-13-affected.log` passes all 25 suites; the final
expanded focused suite in `/tmp/wsdl-p2-13-message.log` passes five cases/80
assertions (372 cases with the 24 other affected suites). WSDL docs in
`/tmp/wsdl-p2-13-docs.log` are warning-free. No native code changes.

The independent test completes 160 element documents with lxml and pinned
Xerces, covering actual SOAP 1.1/1.2 bindings, body/header separation, both
directions, exact names/text/placement, provider types and reconstructed
examples. Its eight failing `P3-integer-lexical-rejection` subtests explicitly
require rejection of `invalid` as xs:int. Existing XsdBaseType conversion
returns int(val), which turns that text into zero. No scalar workaround or
premature P3 implementation is added. The log is
`/tmp/wsdl-p2-13-independent.log`; all remaining assertions, including the
complete independent document count and verdicts, finish successfully.

Full Python discovery runs 77 tests with 14 subtest failures: these eight P3
cases plus the existing four P4 nested-choice and two P6 binding-version
cases. No other failures; see `/tmp/wsdl-p2-13-python.log`. The request survey
and full coverage are recursively identical to P2-12 except for the module
digest. Strict failures remain zero; 360 broad failures and unassessed value
stages stay visible, with no missing or skipped stages. Reports:
`/tmp/wsdl-survey-p2-13.json`, `/tmp/wsdl-coverage-p2-13.json`.

Normative reference: [WSDL 1.1 sections 2.3, 3.5 and 3.7](https://www.w3.org/TR/2001/NOTE-wsdl-20010315).
