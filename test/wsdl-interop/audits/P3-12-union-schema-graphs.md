# P3-12 audit: bounded schema union traversal

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: WSDL Qore code, Qore/Python regressions, documentation and reports.
The full audit-changes skill and its module structure, sandboxing, cooperative
cancellation and DataProvider guide references were applied. Every checklist
item is recorded below. No C++ changes or Valgrind requirement in this increment.

Root cause: duplicate nested members were revisited by schema serialization,
deserialization and native-list metadata queries. Nested rejection explanations
also doubled at each graph edge. The baseline 7-level test records 256 terminal
calls instead of one; the new 32-level graph checks bounded visits and diagnostics.
Typed per-conversion caches preserve declaration order and all contextual inputs.
Only ordinary SOAP rejections are reused, with cancellation/error cleanup and cycle
rejection. The provider input comparator is shared without a semantic change.

Audit fixes retain the legacy "union types" diagnostic phrase and compare reference
maps with signed-zero/NaN/number-precision identity. A signed-zero reference-map
reproduction first raised a false cycle; the corrected regression passes. Cleanup
is registered before context initialization. No supported case or requirement is
removed to make the checks pass.

Validation: 56 affected Qore suites / 658 cases; focused schema graph tests 5 cases /
143 assertions and existing provider tests 11 cases / 197 assertions. Full Python:
125 tests with exactly the same 33 previously recorded P4/P5/P6 failures, no new
errors or skips. New independent atomic/list graph matrices check actual SOAP 1.1/1.2
bindings, both directions, attributes/repeated values, detached reconstructed
providers and examples. Final logs: /tmp/wsdl-p3-12-final-* and individual affected
/tmp/wsdl-p3-12-reviewed-*. Initial missing-catalog survey and intermediate diagnostic
failures remain separately preserved.

Both final corpus reports are identical to P3-11 outside version metadata: strict
89 descriptions / 756 directions / 664 value checks, no selected failures and 220
broad failures. WSDL SHA-256: 6a7392fb7c50bfb65ea31f474dbef8e975c5ab9a55d5a8f105e75c84846e0c97. AOT and WSDL docs builds are warning-free.
Core afded8c83 and XML a28bfa6 are the preceding committed prerequisites. Nothing
is pushed. Union value/enum/retained-pattern requirements remain the next P3 work.
