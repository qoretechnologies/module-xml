# P5-20j scoped identity tuple audit

Copyright (C) 2026 Qore Technologies, s.r.o.

The audit-changes skill and all five referenced guides were consulted for the
exact XML change set. This increment implements the former P5-20f prototype,
including actual typed capture, scoped tuple validation, ownership, native
provenance, empty-record handling, tests and documentation. It introduces no
XML C++ changes, app registration or external production I/O.

The initial gate found an empty-list record regression and two obsolete native
empty-value expectations; these were corrected before the final 191-suite run.
Additional output checking reproduced pre-existing anyType provenance loss on
committed47122aa; native mode now preserves absence of xsi:type. Documentation
exposed a separate astparser grammar defect, root-caused and fixed/tested in
/tmp/wsdl-astparser-select-call; main Qore remains untouched.
