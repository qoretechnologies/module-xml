# P2-12 audit: colliding element declaration fields

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: the incremental changes after the P2-11 snapshot. Internal construction
retains expanded element identities until composition completes; public fields
use local names where unambiguous and expanded names for collisions. Provider
metadata and examples consume that field map, while XML serialization uses the
actual declaration name. Nested anonymous types now enter finalization.
