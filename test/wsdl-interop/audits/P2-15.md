# P2-15 audit: named mixed emptiable simple-content bases

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only changes after P2-14, adding construction metadata for particle
emptiability, effective mixed flags and empty-extension inheritance; named mixed
simple-content restrictions; nested group reference validation; tests and docs.
No ordered instance matcher or general mixed-content runtime is introduced.

WSDL SHA-256: `dfe994b06eaaee51bbf9576ed038c2bb951ccc69b74ce7bae70540b5128acaf9`. Reviewed diff:
`/tmp/wsdl-p2-15-WSDL.diff`; baseline:
`/tmp/wsdl-p2-14-pre-mixed-base-WSDL.qm`.

Root cause: the old simple-content finalizer rejected every named complex base
without simple content, including valid mixed emptiable bases. Mixed flags and
nested group structure were discarded during construction. Named group resolution
also only visited direct group references, missing nested cycles and undefined
references. Four of five initial focused cases failed in
`/tmp/wsdl-p2-15-before.log` (three valid construction failures and a missed error).

Final focused suite passes six cases / 61 assertions, including a shared group
graph with 32 doubled-reference levels and schema reconstruction
(`/tmp/wsdl-p2-15-focused.log`). All 26 other affected suites pass; the combined
runs total 385 Qore cases. The affected-run log includes the earlier five-case
focused variant; the final focused suite was expanded and rerun independently.
`/tmp/wsdl-p2-15-affected.log` records all other suite results.

Independent tests pass 35 schemas and 28 SOAP documents, checking actual 1.1/1.2
bindings, both directions, exact names/text/attributes, native integer values,
providers, generated examples and reconstructed WebService objects
(`/tmp/wsdl-p2-15-independent.log`). The full final Python run has 81 tests and
only 14 tracked subtest failures (eight P3, four P4, two P6), without additional
failures or skips (`/tmp/wsdl-p2-15-python-final.log`). WSDL documentation builds
warning-free (`/tmp/wsdl-p2-15-docs.log`). The request survey and coverage compare
recursively identical to P2-14 except verified digest: zero strict failures,
360 broad failures, no missing/skipped stages. Reports are refreshed from
`/tmp/wsdl-survey-p2-15.json` and `/tmp/wsdl-coverage-p2-15.json`.

References: XSD 1.0
[complex-type property mappings](https://www.w3.org/TR/xmlschema-1/#Complex_Type_Definition_details),
[complex type representation](https://www.w3.org/TR/xmlschema-1/#src-ct),
[particle emptiability](https://www.w3.org/TR/xmlschema-1/#cos-group-emptiable), and
[derivation restriction](https://www.w3.org/TR/xmlschema-1/#derivation-ok-restriction).
Second-edition errata were checked. libxml2 incorrectly ignores outer facets on
restrictions of mixed bases (four negative documents) and retains an outer
mixed=true when complexContent overrides it with false/0 (two invalid schemas).
The exact differing lxml verdicts are asserted; Xerces and Qore enforce the
normative mappings. The review also distinguished a directly empty sequence
from a sequence containing an empty choice: only the former has empty effective
content in an element-only extension and inherits its base content unchanged.

All 62 audit-changes items follow; its five referenced core designs were read
during this execution. This increment does not close P2-10 native memory checks.
No astparser changes, commit, installation or push.
