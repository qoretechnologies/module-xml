# P2-18 audit: attribute wildcard construction

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only construction changes after P2-17, typed public metadata,
focused/independent tests, documentation and refreshed current reports. Baseline:
`/tmp/wsdl-p2-17-pre-attribute-wildcards-WSDL.qm`; reviewed diff:
`/tmp/wsdl-p2-18-WSDL.diff`. WSDL SHA-256: `bb4758d5edf341accd03814fd4d077c886713f097e5470e96706a8e9ac36d08c`.

Root cause: anyAttribute was reduced to a boolean shared with element wildcards;
namespace constraints and processing strength were discarded, including from
attribute groups and base types. Restrictions therefore admitted new attributes
without checking base wildcard permission and accepted invalid wildcard changes.

The implementation retains typed namespace/processing metadata, captures each
source's target namespace, composes nested group intersections and extension
unions, and enforces restriction admission, intensional subsets and processing
strength. It preserves empty-set versus absent-wildcard distinctions and the
anyType ur-type exception. Non-expressible XSD 1.0 combinations are errors;
algorithms do not approximate them with a broader wildcard. Existing runtime
wildcard value behavior remains assigned to P5, not claimed complete here.

References: [XSD complex-type property mapping](https://www.w3.org/TR/xmlschema-1/#Complex_Type_Definitions),
[derivation-ok-restriction.2.2 and .4](https://www.w3.org/TR/xmlschema-1/#derivation-ok-restriction),
[wildcard namespace admission](https://www.w3.org/TR/xmlschema-1/#cvc-wildcard-namespace),
[intensional subset](https://www.w3.org/TR/xmlschema-1/#cos-ns-subset),
[union](https://www.w3.org/TR/xmlschema-1/#cos-aw-union),
[intersection](https://www.w3.org/TR/xmlschema-1/#cos-aw-intersect).
Second-edition errata checked; no relevant correction.

The initial six-case focused suite failed all six cases before implementation
(`/tmp/wsdl-p2-18-before.log`). The expanded suite now passes eight cases / 67
assertions, including imported/no-target namespaces, group processing precedence,
view isolation/reconstruction, failed-addition recovery and typed consumers.
All 30 affected suites pass: 405 Qore cases (`/tmp/wsdl-p2-18-affected.log`).

Independent tests pass 82 schema graphs through 164 actual SOAP 1.1/1.2 binding
parses and 112 original/emitted SOAP documents. They exercise simple/complex
content, qualified/unqualified attributes, request/response processing,
reconstructed services, generated examples and providers; exact boolean false,
integer zero, attribute names and error categories are checked
(`/tmp/wsdl-p2-18-independent.log`). Xerces agrees with every normative verdict.
Two libxml2 subset disagreements are explicitly asserted: it accepts ##local as
a subset of ##other and rejects the empty set as a subset of ##other. Qore
follows cos-ns-subset.3.2.2 without an oracle skip or weakened expectation.

The first consumer worker draft inferred a nested-hash-only value from its
literal and rejected insertion of the integer simple content. The test helper
now allocates hash<auto> explicitly; this was not a production SOAP defect.

Full Python: 87 tests with only 14 already tracked subtest failures (eight P3
lexical, four P4 choice, two P6 binding-version), no new failure/skip
(`/tmp/wsdl-p2-18-python.log`).
WSDL documentation builds without warnings/errors (`/tmp/wsdl-p2-18-docs.log`).
Both-version survey and complete coverage are recursively identical to P2-17
except the module digest: zero strict failures, 360 broad failures, no missing
or skipped stages. Installed Qore and local XML artifact metadata are unchanged.

All 62 checklist items follow; the skill and its five referenced design guides
were read during execution. No native/astparser edits, installation, commit or
push. P2-10's native memory-check decision remains open; this incremental audit
does not clear that gate.
