# P3-28 audit: binary facets and union lexical values

Copyright (C) 2026 Qore Technologies, s.r.o.

The complete audit-changes checklist and referenced module-structure, sandboxing,
cooperative-cancellation and DataProvider checklist/development guides were applied
to the final WSDL changes, six changed Qore suites, Python matrices and coverage,
strict selection/current reports, durable design, evidence, examples and release
notes. No Qore-core files or C++ changed.

Audit findings fixed before commit: selected union-member whitespace was not
propagated to enclosing patterns; binary carriers were rejected in captured union
lists; union output metadata omitted carriers; and binary union serialization
relied on implicit lexical restoration across the atomic raw-string boundary.
The HTTP test rejected extending the raw-string convention to union strings.
Final behavior explicitly preserves the existing union lexical input contract.

Checklist: **21 Pass, 41 N/A, 0 Fail**. Exact final test evidence and hashes are in
[EXECUTION.md](../EXECUTION.md) and the recorded final hash manifest.
