Audited 2026-09-11 against parent `09b3abc`, using the complete
`/home/david/.codex/skills/audit-changes/SKILL.md` and all five referenced guides.
Every one of its 62 individual checks is recorded: **19 Pass, 43 N/A, 0 Fail**.

The change admits concrete child substitution members at the original particle
position and converts each selected member using its declaration. Occurrence
limits, all slots, member namespaces, presence and incremental schema consistency
are tested with both actual SOAP bindings and both directions. Flattened records
and explicit part wrappers preserve the same member fields.

The final 120-suite gate passes 1229 cases/60607 reported assertions without
warnings. Source AST/IR/JIT/tiered and AOT each pass the 14-case/1507-assertion
suite and the 53-schema/310-document/2586-row independent matrix. Xerces validates
all 992 SOAP outputs and 58 standalone samples per matrix. Compiled provider,
HTTP, Cargo and CDA consumers, earlier declaration/final/value matrices, the
executed design example and all 16 survey harness methods pass. The changed
strict-coverage harness method passes separately; the known P6 dual-binding
finding remains open and is not counted as a passing full coverage test suite.

The complete corpus has 2457 rows, no added failures, and four removed original
SubstitutionGroup deserialization failures. Strict selection passes 143 WSDLs
and 1384 directions with no value failures or missing stages. The 64 broader
failures remain visible. No upstream fixture or historical finding was changed.
The [inventory](../P5-07-validation.json) records commands, exact artifacts,
fixture/log hashes, accounting and every audit item.

This increment changes no native code; the XML qmod, private libxml2 and isolated
libqore are unchanged. The independent native EDC omission is explicitly retained
as a failed P5 requirement owned by the next native increment. P5 and P6–P9 remain
open. Both origins were fetched; neither develop has incoming commits. Main Qore's
concurrent changes were preserved, and this work made no main-Qore edits or pushes.
