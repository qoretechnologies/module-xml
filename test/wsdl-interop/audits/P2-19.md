# P2-19 audit: declaration constraints

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only schema construction changes after P2-18, focused and independent
tests, consumer worker, documentation and refreshed current reports. Baseline:
`/tmp/wsdl-p2-18-pre-declaration-constraints-WSDL.qm`; reviewed diff:
`/tmp/wsdl-p2-19-WSDL.diff`. WSDL SHA-256: `42512cfc525dd1bf506f228a9d3d1b4e3e104cc53065744be9810b11fdea9fba`.

Root causes: element construction selected the first of contradictory type
alternatives and did not distinguish declaration/reference/local/global property
constraints. Empty type names reached a doType assertion. ID-dependent value
constraints and combined attribute-use restrictions were not checked after
resolution. An empty local declaration could disappear during typed iteration.

Construction now rejects those invalid declarations, keeps valid anonymous empty
complex types, validates declaration boolean spellings and resolves ID ancestry
before constraint checks. The element constraint pass follows anonymous complex
type finalization; merged inherited ID uses are checked before publication.
General element default/fixed application, abstract-element runtime validation
and ID/IDREF document binding remain assigned to P5. Occurrence matching is P4.

Requirements: [element representation](https://www.w3.org/TR/xmlschema-1/#src-element),
[attribute constraint rule 3](https://www.w3.org/TR/xmlschema-1/#a-props-correct),
[element constraint rule 5](https://www.w3.org/TR/xmlschema-1/#e-props-correct),
[complex-type rule 5](https://www.w3.org/TR/xmlschema-1/#ct-props-correct),
[schema-for-schemas grammar](https://www.w3.org/TR/xmlschema-1/#normative-schemaSchema),
and [boolean whitespace](https://www.w3.org/TR/xmlschema-2/#rf-whiteSpace).
Second-edition errata checked; no relevant correction.

The original seven-case test failed all seven cases before implementation
(`/tmp/wsdl-p2-19-before.log`). The final test passes eight cases / 97 assertions
(`/tmp/wsdl-p2-19-focused.log`), including empty/repeated declarations in all
compositors and groups, late/anonymous ID types, inherited/grouped ID uses,
prohibition, recovery from early and late failures, preserved prior objects,
provider integer zero and Serializable reconstruction. All 31 affected suites
pass: 413 Qore cases (`/tmp/wsdl-p2-19-affected.log`, all suites include the final source and tests). No test warning was reported.

Independent tests pass 94 schemas through 188 actual SOAP 1.1/1.2 binding parses
and 24 original/emitted documents in both directions. Reconstructed services,
providers and generated examples preserve integer/boolean types, zero/false,
expanded names and ordering; missing/wrong-namespace values reject with the
intended SOAP-DESERIALIZATION-ERROR (`/tmp/wsdl-p2-19-independent.log`).

Oracle disagreements are asserted explicitly, independently of Qore expectations.
libxml2 admits twelve invalid schemas with ID-derived constraints/uses and
rejects two legal whitespace-padded declaration booleans. Xerces agrees except
for two ID-derived complex simple-content value constraints, which it accepts
contrary to e-props-correct.5. No invalid schema becomes a Qore success or skip.

WSDL documentation builds without warnings/errors (`/tmp/wsdl-p2-19-docs.log`).
Both corpus reports differ from P2-18 only by WSDL digest and the externally
updated installed Qore revision (now b46682ff4d02341350b02cd55621a0a540c032a4).
Results are unchanged: zero strict failures, 360 broad failures, no missing or
skipped stages. The local Debug XML artifact remains
dc1fadc47062c8d809cd8e04ffb8611edd2ffe03baf08b26f284b5cedbd98372.

An initial full run exposed a new expired-namespace access in the ID attribute
check. Imported/cached types borrow their namespace object, whose lifetime can
end before late constraint resolution. ID ancestry now follows the resolved
type chain directly, with a visited set, without accessing that namespace. The
new detached-schema regression fails before the fix and passes after it
(`/tmp/wsdl-p2-19-lifetime-before.log`); both imported reference-permission tests
pass after the fix (`/tmp/wsdl-p2-19-reference-recheck.log`).

Final Python: 89 tests in 110.904s, with only the same 14 tracked subtest failures
(eight P3 lexical, four P4 choice and two P6 binding-version), no new failure,
error or skip (`/tmp/wsdl-p2-19-python-final.log`).

All 62 items follow. The skill and its five referenced design guides were read
during execution. No new native/astparser change, install, commit or push. The
P2-10 native memory-check decision remains open; this Qore-only incremental
audit does not clear that gate.
