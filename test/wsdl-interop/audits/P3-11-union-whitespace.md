# P3-11 audit: XML and union whitespace

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: native XML text/CDATA/formatting and data projection, union facet/comment
handling, element-only schema/SOAP views, tests, an authored fixture correction,
provider dead-code/documentation cleanup, reports and implemented design. The separate core documentation prerequisite is afded8c83.
The full audit-changes skill and its module structure, sandboxing, cancellation
and DataProvider guide references were reviewed; every item is below.

Audit corrections include regrouping repeated children after omitting indentation,
CDATA formatting, inherited space for subtree readers, schema/SOAP whitespace
views, and cancellation/ownership at new loops. The local i4452 fixture now declares
its intended mixed content; both independent compilers prove the old declaration
invalid for its unchanged text/CDATA cases. The AOT build exposed an unreachable
break after SOAP-SEARCH-ERROR; removing it produces a warning-free build. Stale provider class/path and inherited-method references are corrected against the actual API; its example executes against test/example.wsdl.

All 55 affected Qore suites pass 653 cases. The offline Salesforce connection case
adds two assertions; its account/network case was outside the selected check.
Final targeted Python runs six tests; full discovery ran 122 tests before adding
the independent fixture test. Its 33 failures are the seven existing P4/P5/P6
failures plus 26 subtest/accounting failures in two explicitly named P6 requirement
groups. Baseline runs prove those binding failures predate this change. No new
P3 failure, error or skip is hidden. Native/WSDL/provider docs and native/AOT builds
are warning-free. Logs: /tmp/wsdl-p3-11-final-*, plus fixture-dependent reruns named
in union-whitespace-evidence.md. Valgrind reports zero errors and no definite,
indirect or possible leaks; its previously adjudicated core DWARF metadata warning
remains visible. PCRE2's supported QORE_PCRE2_NO_JIT=1 control is used; no suppression.

Strict coverage remains 89 descriptions/756 directions and 664 value checks with
no selected failures. All 220 broad failures, source hashes and counts remain;
only two LocalElementSimpleType invalid-source diagnostics are more precise.
