# P2-16 audit: schema reference import permissions

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only schema construction changes after P2-15; source-local import
permissions, namespace attribute presence, dependency-reference identity, tests,
three authored fixture corrections, documentation and refreshed current reports.
WSDL SHA-256: `4faccd75b554d33c005383726a86ab072aabc2e6f91fa29e3749c8da38aa5e80`. Reviewed diff:
`/tmp/wsdl-p2-16-WSDL.diff`; baseline:
`/tmp/wsdl-p2-15-pre-reference-permissions-WSDL.qm`.

Root cause: getTypeHash expanded QNames without verifying whether the referencing
source imported a foreign namespace. Components loaded elsewhere therefore made
invalid references succeed. Import comparisons/cache keys also collapsed absent
and explicitly empty namespace attributes, and empty targetNamespace was accepted.
The corrected focused regression run against an isolated P2-15 snapshot fails four
of five cases because WSDL-ERROR is absent
(`/tmp/wsdl-p2-16-before-corrected.log`). The initial earlier baseline run had a
test-helper default-argument error in its no-namespace setup; it is not used as
defect evidence. The final focused suite has five cases / 53 assertions, including
all component reference kinds, absent/empty namespaces, transitive/includes,
cache reuse, rollback and reconstruction. All 28 affected suites pass: 390 Qore
cases (`/tmp/wsdl-p2-16-affected.log`).

Three Qore-authored SOAP fixtures (`test/test.wsdl`, `test/soap-comprehensive.wsdl`
and the inline contract in `test/soap-features.qtest`) lacked imports for their
soapenc:Array references. Each now declares the encoding namespace explicitly;
all prior payload assertions pass. Pinned upstream source bytes are untouched.

Independent checks pass 29 schema graphs and 24 SOAP documents with actual SOAP
1.1/1.2 bindings, both directions, exact names/integer/boolean values, providers,
generated examples and reconstructed WebService consumers
(`/tmp/wsdl-p2-16-independent.log`). Normative schema expectations are enforced
by Qore; the test separately asserts the precise known validator discrepancies:

- libxml2 accepts four missing-import references to preloaded type definitions
  (restriction base, list item, union member and complex base), an explicit empty
  import namespace resolving to a cached no-target schema, and two invalid
  empty/whitespace targetNamespace declarations (seven graphs).
- Xerces treats explicit-empty import namespaces as absent in a reference
  permission case and a cached import target case (two graphs).

References: [src-resolve.4](https://www.w3.org/TR/xmlschema-1/#src-resolve),
[src-import.1 and .3](https://www.w3.org/TR/xmlschema-1/#src-import), and
[XSD schema namespace property mapping](https://www.w3.org/TR/xmlschema-1/#Schemas).
An absent-namespace reference requires an import with no namespace attribute,
and a present import namespace requires a matching targetNamespace attribute;
explicit empty values do not meet those conditions. A schema's target namespace
cannot be an empty string. Second-edition errata were checked. No oracle skip or
Qore validation workaround is introduced.

Full Python runs 83 tests with only the 14 tracked subtest failures (eight P3,
four P4, two P6): `/tmp/wsdl-p2-16-python.log`. WSDL docs build warning-free
(`/tmp/wsdl-p2-16-docs.log`). Survey and coverage retain every counter, stage and
failure classification from P2-15: zero strict failures, 360 broad failures, no
missing/skipped stages. The already-rejected SOAPEncodedArray description now
reports the unimported WSDL-namespace QName `string` from its `arrayType` annotation
instead of a later missing-type error; error category remains WSDL-ERROR.
