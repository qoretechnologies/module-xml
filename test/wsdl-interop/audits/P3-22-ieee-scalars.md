Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: the WSDL IEEE helper/provider and scalar/example integration, the updated
interop assertion, new Qore/Python/.qr regressions, release notes, implemented
design, validator evidence, current corpus reports, README and execution record. The full audit-changes
skill and applicable module-structure, sandboxing, cancellation and DataProvider
guides were reviewed. The scalar provider adds no app/action or record schema.

All 65 affected Qore suites pass 748 cases / 16120 assertions. The new suite
passes 6 cases / 793 assertions in AST, IR, JIT, tiered and AOT execution. The
focused three-suite matrix passes in all four modes. AOT compilation,
Qdx/Doxygen and the executed documentation example are clean.

Full Python discovery runs 160 methods in 700.836 seconds with exactly the
preceding 33 P4/P5/P6 failure signatures, no new/removed failures, zero errors
and zero warnings. The new seven-method matrix passes, including 12576 exact
rational-reference conversions and 5544 document verdicts. The 72 source-
adjudicated libxml2 exponent false positives remain explicitly checked;
Xerces and the normative grammar reject every such invalid input.

Both-version corpus counts and statuses remain unchanged: 89 selected WSDLs /
756 directions with zero selected failures, and 220 broad tracked failures.
Two survey diagnostics, four coverage diagnostics and 16 output bodies reflect
correct target rounding and safe serialization. Independent rational checks
against the original corpus values confirm the 16 changed outputs. The
current reports contain the exact tested survey/coverage data; historical
findings and all original fixtures remain unchanged.

Source and runtime hashes stayed frozen during the full run. The production
WSDL SHA-256 is 3e9aa3351b0933110dffa7905f6b9249995ece492b70d980cf0789cdb61f57e8.
The native XML/core binaries are unchanged from P3-21; no C++ changes require
another Valgrind run. Main Qore remains clean on develop at 9dab82749. No push
or installation is part of this increment. Final diff, documentation links,
file modes and all 62 checklist entries were reviewed after verification.
