# P2-20 audit: unwrapped document values

Historical audit of the intermediate P2 candidate. Open gates below describe that
earlier state; P2-24 through P2-31 and EXECUTION.md record the separately tested
commits that supersede this candidate. Original findings are retained as evidence.

Copyright (C) 2026 Qore Technologies, s.r.o.

Scope: Qore-only message argument selection and parsed-content metadata after
P2-19, new focused/independent tests and worker, documentation/current reports.
Baseline `/tmp/wsdl-p2-19-pre-bare-values-WSDL.qm`; reviewed diff
`/tmp/wsdl-p2-20-WSDL.diff`. WSDL SHA-256: `cb7c2e6a3471a6c78f237fa9c8ffca5bb4d5540b9333d2767318674d6d40ba11`.

Root cause: unwrapped argument selection used only elementmap and treated
wildcard-only or nested-choice-only content as empty. The selection helper also
lacked a way to protect separately addressed header values when collecting
wildcard children. Multiple selected parts did not identify which part owned a
bare field.

The implementation retains an explicit parsed element-wildcard flag independent
of attribute wildcards, excludes absent zero/zero particles/ancestors, accounts
for choice maps in emptiness and field selection, and collects only one selected
part's unwrapped value. Other part/header/message wrappers are reserved. Legacy
message-name containers and colliding declared field names remain eligible;
caller data is copy-on-write. Full group expansion, wildcard admission/matching,
mixed content and lossless XML carrier consumers remain tracked P2/P4/P5 work.

Requirements: the existing native argument contract and the wire ownership of
[WSDL 1.1 SOAP body parts](https://www.w3.org/TR/2001/NOTE-wsdl-20010315#_soap:body)
and [header parts](https://www.w3.org/TR/2001/NOTE-wsdl-20010315#_soap:header).
The undated /TR/wsdl URL now redirects to WSDL 2.0, so these references pin the
WSDL 1.1 Note. XSD zero/zero particle absence follows
[element particle mapping](https://www.w3.org/TR/xmlschema-1/#element-element).

The initial focused test had three failures out of five cases
(`/tmp/wsdl-p2-20-before.log`). The expanded test passes six cases / 116 assertions
(`/tmp/wsdl-p2-20-focused.log`). It checks actual 1.1/1.2 bindings, both directions,
reconstruction, exact wildcard identities/values, typed zero/false choice values,
choice exclusivity, header separation, multipart ambiguity/wrappers, absent
particles and attribute-only wildcard rejection. A message-container regression
was found and fixed before final verification (`/tmp/wsdl-p2-20-scope-before.log`).

The independent test passes 60 original emitted payload/header documents, across
four schemas and eight actual bindings, request/response processing, reconstructed
services and bare/part-wrapper/message-container input forms. libxml2 and pinned
Xerces agree on every emitted document. Assertions check exact expanded names,
values and order, including zero/false/empty and header content. The first worker
draft used an inferred hash-of-hash value before inserting its scalar context;
allocating hash<auto> explicitly fixed that test-helper error, with no production
change (`/tmp/wsdl-p2-20-independent.log`).

All 32 affected Qore suites pass: 419 cases, no warnings
(`/tmp/wsdl-p2-20-affected-final.log`). Full Python: Ran 90 tests in 118.806s, with only the same
14 tracked subtest failures (eight P3 lexical, four P4 choice, two P6 binding
version), no new failure/error/skip (`/tmp/wsdl-p2-20-python.log`). Docs build
without warnings/errors (`/tmp/wsdl-p2-20-docs.log`). Both corpus reports are
recursively identical to P2-19 except WSDL digest: zero strict failures,
360 broad failures, no missing/skipped stages. Runtime/artifact metadata is
unchanged. Reports are refreshed from the final source.

All 62 checklist items follow. The skill and five referenced design guides were
read during execution. No new native/astparser change, installation, commit or
push. P2-10's native memory-check decision remains an open gate.
