## Review findings and verification

- Fixed declaration-scoped simple-content/type/group dependencies, import/include
  namespace checks, chameleon instances, cycles and source-based reconstruction.
  False, zero and empty content retain the existing scalar/attribute representation.
- Qualified attribute processing retains inherited/shadowed prefixes, local form
  overrides and expanded-name collisions. Unknown ordinary attributes reject;
  fixed/default values remain typed. Exact duplicate live uses reject. Prohibitions
  are not use components; local groups resolve before inheritance and cannot remove
  required base attributes without a required replacement.
- Audit found empty base/itemType attributes bypassing exclusivity checks. New
  regressions reproduced the failures and now pass with presence-based checks.
- Audit found exponential shared-union traversal in the new list-item predicate:
  a 20-level diamond exceeded a 10-second deadline. Per-type memoization reduces
  the full focused suite to under one second. Multi-group attribute merging is
  linear in the contributed uses; repeated identical schema references reuse
  validated modes, preserving separate import/include checks.
- Namespace traversal materializes only used attribute prefixes. A 128-level
  regression checks exact declaration counts and the leaf identity. Sibling scope,
  failure recovery, reserved bindings and caller-input immutability pass.
- The synthetic SOAP response omitted an enc declaration present in its original
  XML comment; the original remains an explicit negative, and the positive copy
  adds that declaration. Array unit tests now carry the enclosing output namespace
  context used by their serialized fragments. All existing SOAP array cases pass.
- Issue4449 original bytes are unchanged and remain negative composition inputs.
  Corrected derivatives have exact substitutions and original/derived checksums;
  both validators and the consumer request round trip pass.
- Qore debugging tests: 307 cases pass in 18 suites, without warnings or
  unhandled errors. Logs: `/tmp/wsdl-p2-audited-*.log`. soap.qtest catches three
  assertion failures intentionally in its comparator negative cases.
- Python: 67 tests ran; 66 pass and one test reports two failing P6 subtests, for
  SOAP 1.1 request/response envelope selection in a dual-binding contract. All
  P2 payload assertions and the 28-document independent simple-content oracle run
  before those version assertions. The separate actual SOAP 1.1/1.2 attribute
  contracts pass exact value/QName checks in both directions. This is not a green
  full-suite result and the P6 failures are not skipped or counted as passing.
- The execution prompt explicitly permits routing independent later-phase findings.
  Binding version selection still uses namespace availability instead of the
  selected binding. No P6 implementation change or phase-order exception was made.
  The ordering question remains unanswered; P2 independent work can continue.
- Strict gate: 38 descriptions / 140 message-directions, zero selected failures.
  Full diagnostic coverage: 384 failures (P2=8, P3=208, P4=76, P5=92), zero missing
  or skipped stages. All 293 descriptions / 2,272 directions remain accounted for.
  Every previous requirement success is retained. Twenty existing wire bodies
  change for defaults or correct element/attribute qualification; sixteen previously
  encoded source-invalid directions now reject with SOAP-DESERIALIZATION-ERROR.
- Both-version catalog survey completes; its full counts remain in current-report.json.
  Archive, historical findings and source adjudication bytes/hashes are unchanged.
  Python fixtures retain offline dependencies and pinned independent versions.
