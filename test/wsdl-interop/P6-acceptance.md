The ordinary projection remains distinct from explicit native capture and retained XML as accepted in P5; diagnostic legacy projection failures are not reclassified as passing. P6 does not claim WS-I profile conformance or complete SOAP processing, MTOM/SwA reference semantics, encoding or CI acceptance.

All 203 phase-boundary Qore suites pass: **3,257 cases / 136,416 assertions**. All 18 independent Python gates and 16 corpus commands meet their expected outcomes. The new port-address suite passes 4 cases / 519 assertions in both source and compiled WSDL; its loopback loaders cover 63 HTTP exchanges, while the independent Python peer covers another 28. Six corpus reports match P6-44 except for the WSDL source hash. Documentation and three-file astparser checks pass without warnings/errors.

The exact executable commands and totals are recorded in [P6-45 validation](P6-45-validation.json); [P6-44](http-request-url-evidence.md) records request-local transport and handler route evidence. The [P6-45 audit](audits/P6-45-port-locations.md) covers all 62 checks. P7 implementation begins only after these phase-boundary checks. The complete XML development plan remains open and changes remain local until final completion.
