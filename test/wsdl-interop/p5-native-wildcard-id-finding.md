# Native wildcard ID errors are detected but not reported

Copyright (C) 2026 Qore Technologies, s.r.o.

Status: independently reproduced native validation defect; assigned to P5-11.
P5-10 implements the WSDL instance layer separately. This remains a failure
until the native DOM and reader paths reject the required negative cases.

[XSD 1.0 Structures section 3.4.4, clauses 5.1 and 5.2](https://www.w3.org/TR/2004/REC-xmlschema-1-20041028/#cvc-complex-type)
limit wildcard ID attributes to one and exclude them when the type declares an
ID attribute use, even if that declared attribute is absent. Skip processing
does not assess wildcard IDs. Xerces-J 2.12.2 rejects all six negative fixtures
in `test_wildcard_attributes.py` with the corresponding constraint diagnostics.

Both lxml's libxml2 2.12.10 and the native private libxml2 2.15.4 accept these
violations. In `xmlSchemaVAttributesComplex()`, libxml2 sets
`XML_SCHEMAS_ATTR_ERR_WILD_DUPLICATE_ID` and
`XML_SCHEMAS_ATTR_ERR_WILD_AND_USE_ID`. Its final error-reporting switch handles
neither state. The default branch silently discards them. The original pinned
source already contains this omission; P5-10 has not changed native code.

A minimal schema declares two global `xs:ID` attributes and a root with a
strict attribute wildcard. Supplying both attributes with distinct values
isolates the per-element wildcard rule from duplicate document IDs.
`/tmp/wsdl-p5-10-native-wild-id.qr` and its log reproduce acceptance through
`parse_xml_with_schema()` and `XmlReader` (`isValid() == True`). The complete
schema and instance are also generated by the independent matrix's
`ids-strict-False/True` fixture. All six normative negatives remain required
rejections in WSDL and Xerces tests; the lxml discrepancy is explicitly recorded.

P5-11 must add the missing native error reports, a behavioral configure probe,
DOM/reader and independent regressions, and exception/cancellation/Valgrind
checks before committing its dependency change. The provider selection must
reject a system library that exhibits this behavior.
